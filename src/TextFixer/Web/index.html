Help


Review text from Chrome
  1. Select text inside an editor.
  2. Right-click and choose "Review selection in TextFixer".
  3. Review starts automatically. Accept or reject corrections, then choose "Apply in Chrome".
The Chrome extension edits the captured editor directly. Set up the connection in Settings. Some editors are not supported.


Review text with Alt+Q
  1. Select any text you can copy, in an editor or on a web page, then press Alt+Q.
  2. Review starts automatically. Review the suggestions.
  3. Choose "Paste with formatting" to replace the selection, or copy the revision.
Alt+Q uses the clipboard. When copied HTML is available, TextFixer preserves its paragraph markup and formatting. The destination controls how pasted HTML appears. Plain-text replacement is an explicit option and can remove formatting. For read-only text, such as a web page paragraph, TextFixer offers only copying the revision.


Translate with Alt+E
  1. Select any text you can copy, then press Alt+E.
  2. TextFixer translates German into English and other languages into German.
  3. Choose "Replace selection" to paste the translation over your selection, or copy it.
To adjust the translation, describe the change in the field below it, for example "more formal", "use du" or "shorter", and choose Revise. Each revision starts from the current translation. The translation is pasted as plain text. For read-only text, TextFixer offers only copying the translation.


Fact check with Alt+W
  1. Select any text you can copy, then press Alt+W.
  2. TextFixer finds the checkable claims and researches each one on the web.
  3. Each claim shows a verdict, an explanation and the sources found. Open a source to read it in your browser.
"Supported by the sources found" means the cited sources back the claim; it is not a guarantee. "Can't verify" means the evidence found was not enough. A claim without a cited source is never marked supported or wrong. For a wrong claim, tick its correction to include it in the revised text, then copy it or replace your selection. Formatting is kept as in a review. Use the Review, Translate and Fact check buttons above the results to run another task on the same text. A fact check takes longer than a review and uses more of your plan allowance.


Punctuation style
Settings > Punctuation style sets quotation marks, dashes, ellipses, spaces, the multiplication sign, arrows, and feet and inches separately. "Keep as typed" uses plain characters in corrections and translations and leaves the ones you typed. "Make plain" also converts yours; these appear as Punctuation corrections. "Allow typographic" lets ChatGPT choose.


Shortcuts
Settings > Shortcuts changes the keys for Review, Translate and Fact check. Click a shortcut, press the new keys, and it works right away in every app. Use Ctrl or Alt, or both, with a letter, a digit or F1 to F24. TextFixer refuses combinations that another app already uses, that are needed for editing, such as Ctrl+C, or that type a character on your keyboard layout, such as Ctrl+Alt+Q for @ on German keyboards.
Choose your corrections
Red crossed-out text is removed; green text is added. A removed punctuation mark or space appears in a dashed box labelled "Remove". Click a marked correction to accept or reject it. Choose a review tab: Spelling, Grammar, Punctuation, Wording, Worth checking or Formatting. Counts show available suggestions. The review opens on the first tab with suggestions, or Spelling when all counts are zero. Only the selected category is highlighted and clickable; other corrections appear faded with their current choices. "Accept all" and "Reject all" affect only the selected tab.
Formatting suggestions are checked locally for Alt+Q HTML captures and start unchecked. Formatting previews show Before and After, with spaces as dots. Click a preview or its checkbox to accept or reject that fix. If a text correction touches the same space, reject one of the two suggestions.
"Worth checking" contains questions about reasoning and terminology. Each finding has a kind label. "Use this wording" is available when its first quote matches one place in the captured text. It creates an accepted replacement under Worth checking. "Undo wording" or rejecting that replacement restores the overlapping spelling and grammar choices. Overlapping wording replacements cannot be active together. A disabled wording button has a visible explanation. Rewrites that change line breaks cannot be applied.


Review mode
Settings > Review chooses how the text is checked. "One request for all tabs" sends one request and shows all tabs together. "One request per tab" runs a separate, focused check for each tab, all at the same time. Finished tabs show their count and can be reviewed right away; a spinning ring marks a tab being checked, "!" marks a tab that could not be checked. Copy and paste become available when all tabs are done. Where two tabs change the same text, the tab further left wins.
Clipboard history
Choose "Clipboard history" to see your last 20 copied texts. Choose "Copy plain" to put an entry back on the clipboard without formatting, or "Copy formatted" (shown for formatted entries) to keep bold, links and other formatting. The × removes an entry. Then paste it anywhere. Password manager copies are not recorded. Turn recording off or clear the history in Settings.
After applying
Alt+Q sends the paste but cannot verify the result inside the editor. "Paste sent" describes delivery of the paste command, not confirmation of the resulting text. If the revised text remains on the clipboard, check the editor before pasting again. Check the result in the original editor. Use Ctrl+Z there to undo; Chrome direct edits may need one undo per correction.
Closing this window keeps TextFixer running in the tray. Choose Exit from the tray menu to close the app.

Set up the Chrome connection
  1.  Registers this app for your Windows user.
  2. Open chrome://extensions, enable Developer mode, and use Load unpacked to select chrome-extension. 
  3. Select text inside your Chrome editor, right-click, and choose "Review selection in TextFixer".
An extension capture offers "Apply in Chrome". The status-bar icon identifies the capture source. Alt+Q uses the separate clipboard mode.
